# ローポリのキャラを自分で作る手引き（Blender）

自キャラ（猫）と敵キャラを Blender で作り、このゲームに入れるための手順と注意点。
この手順どおりに作っておけば、開発を再開したときに、ほぼそのままゲームに読み込める。

---

## 0. 全体の流れ

1. Blender を入れて、単位と見え方を整える（1章）
2. 参考画像を置く（2章）
3. 大まかな形を箱や球で作る（ブロックアウト）（3章）
4. 面を整えて、ローポリらしい形にする（4章）
5. 色を塗る（パレットの色の名前の材質を面ごとに付ける）（5章）
6. 動かす部品に分けて、関節の位置に原点を置く（6章）
7. 確認してから書き出す（.glb）（7・8章）
8. メモ（仕様のメモ）を書いて、決めた場所に置く（9章）

敵キャラも同じ流れ。敵ならではの注意は 10章。

---

## 1. 準備

### Blender を入れる
- https://www.blender.org/ から無料で入れる（4.x の最新版でよい）。
- 日本語にする: Edit → Preferences → Interface → Translation で Japanese にする。
  ※ この手引きは英語の名前も書いておく（日本語版では名前が違うことがある）。

### 最初にやる設定
- **単位**: プロパティの「シーン」タブ → Units → Unit System: Metric、Unit Scale: **1.0**、Length: Meters。
  - **1 マス = 1m**。ゲームと同じ大きさで作る（あとで拡大・縮小しない）。
- 最初からある立方体・カメラ・ライトは消す（A ですべて選択 → X → 削除）。カメラとライトは書き出しに混ざると困る。
- **面の向きの表示**: ビューポート右上の「オーバーレイ」→ Face Orientation（面の向き）をオン。
  外向きの面が青、裏返った面が赤で見える。**完成時に赤い所がないこと**。
- 統計の表示: オーバーレイ → Statistics をオン。三角形の数（Triangles）が左上に出る。

### よく使う操作（覚えておくと速い）
| 操作 | キー |
| --- | --- |
| 正面・横・上から見る | テンキー 1・3・7（Ctrl を足すと反対側） |
| 透けて見る | Alt + Z |
| 編集モード切り替え | Tab |
| 頂点・辺・面を選ぶ | 編集モードで 1・2・3 |
| 動かす・回す・大きさ | G・R・S（続けて X/Y/Z で向きを固定） |
| 押し出す | E |
| ループカット（輪切り） | Ctrl + R |
| ナイフ | K |
| 頂点をまとめる | M |
| 辺・面を溶かして消す | X → Dissolve Edges / Dissolve Faces |
| 三角形にする | Ctrl + T |
| 面の向きをそろえる | Shift + N（外向きに再計算） |
| 原点を 3D カーソルへ | 右クリック → Set Origin → Origin to 3D Cursor |
| 3D カーソルを選んだ所へ | Shift + S → Cursor to Selected |
| 変形を確定 | Ctrl + A → All Transforms（または Rotation & Scale） |

## 2. 参考画像を置く

- 6方向の猫の画像（正面・背面・左右・上・底）を使う。
- 正面図（テンキー 1）で Shift + A → Image → Reference で正面の画像を置く。横（テンキー 3）でも同じように横の画像を置く。
- 画像の大きさを、**全高 1.4m** に合うように S で合わせる（足の裏を高さ 0、耳の先を 1.4m に）。
- 画像のオブジェクトは書き出しに入れない（8章で「選んだ物だけ」書き出せば入らない）。

---

## 3. 大きさと向きの決まり（いちばん大事）

ゲームのコードはこの決まりを前提にしている。ここがずれると、読み込んだときに埋まる・浮く・後ろを向く。

| 決まり | 内容 |
| --- | --- |
| 単位 | 1 = 1m。拡大・縮小せずにこの大きさで作る |
| 足もと | **足の裏が高さ 0**（Blender の Z = 0） |
| 中心 | 体の真ん中が X = 0、Y = 0 |
| 正面 | **テンキー 1（正面図）で顔が見える向き**（Blender の -Y 方向を向く）。書き出すとゲームの正面（+Z）になる |
| 左右 | **左右対称**（しっぽ以外）。Mirror モディファイアーで作る（4章） |

### 猫の寸法（今のゲームの猫に合わせた値。目安）
| 部分 | 大きさ・位置 |
| --- | --- |
| 全高 | 耳の先まで約 1.4m |
| 目の高さ | 約 1.05〜1.1m（1人称のカメラは 1.1m） |
| 頭 | 幅 約 0.5m、高さ 約 0.5m、中心の高さ 約 1.0m。2.5 頭身 |
| 胴 | 下が太い卵形。幅 約 0.55m、中心の高さ 約 0.55m |
| 腕 | 肩の高さ 約 0.72m、左右 ±0.24m。短く太い |
| 脚 | 付け根の高さ 約 0.29m、左右 ±0.11m。茶色の四角いブーツ |
| しっぽ | 付け根 高さ 約 0.36m、後ろへ 0.22m。後ろへ伸びてから上へ曲がる。先が白 |
| 耳 | 頭の上の両端。少し外に開く。内側ピンク |
| 当たり判定 | 半径 0.3m の円柱（体の太さはこの中におさめる） |

見た目のルールは `docs/rules/avatar.md`（白いよだれかけ模様、目は小さな黒い四角、など）。

## 4. 形を作る

> 立方体から 1 操作ずつ作る詳しい手順は [modeling-cube-guide.md](modeling-cube-guide.md)。

### 4-1. 左右対称にする（Mirror）
1. 体の右半分だけを作る。X = 0 より左の頂点を消す。
2. モディファイアー（スパナのタブ）→ Add Modifier → Generate → **Mirror**。Axis は X。
3. **Clipping をオン**（真ん中の頂点が X = 0 から離れなくなり、すき間ができない）。
4. 最後に、書き出しの前に Apply（確定）するか、書き出しで「モディファイアーを適用」をオンにする（8章）。

### 4-2. 大まかな形（ブロックアウト）
- 頭: UV Sphere（Segments 8〜10、Rings 6〜7）か、立方体をつぶして作る。
- 胴: UV Sphere を縦に伸ばし、下を太くする（下の頂点を選んで S）。
- 腕・脚: Cylinder（Vertices **8** = 八角形）を短く太く。
- 耳: Cone（Vertices 3〜4）。
- ブーツ: 立方体。
- まず「遠くから見て猫に見える」ところまで、部品を重ねて置くだけでよい。細かい所はあとで。

### 4-3. ローポリらしい面にする（2つのやり方）

**やり方 A: 手で整える（きれいに仕上がる、王道）**
- ループカット（Ctrl + R）で必要な所だけ面を足し、G で頂点を動かして形を出す。
- 不要な辺は Dissolve Edges で消す。目立つ所（顔、胸）だけ細かく、背中や脚は粗くてよい。
- 形の流れ（頬のふくらみ、口元、お腹の丸み）に沿って三角形ができるように、K（ナイフ）で斜めの辺を入れる。
- 「大きさのそろわない三角形が、形に沿って並ぶ」のが目標の見た目。

**やり方 B: なめらかに作ってから間引く（前回の試作と同じ考え方）**
1. Subdivision Surface を付けて丸くするか、スカルプトで形を作る（面が多くてよい）。
2. Apply してから、**Decimate** モディファイアー → Collapse を付ける。
3. **Symmetry をオン**（軸 X）にすると、左右対称のまま減る。
4. Ratio を下げて、ちょうどよい粗さにする（三角形の数は下の目安）。
5. 形が崩れた所だけ、手で頂点を動かして直す。

### 4-4. 三角形の数の目安
| 物 | 三角形の数 |
| --- | --- |
| 猫 全体 | 400〜900 |
| 頭 | 100〜250（顔は細かめ） |
| 胴 | 60〜150 |
| 腕・脚 1本 | 30〜80 |
| しっぽ | 40〜100 |
| 小さい敵 | 150〜400 |
| 大きい敵（ボス） | 600〜1500 |

### 4-5. 気を付けること（形）
- **フラットシェーディング**: オブジェクトを右クリック → **Shade Flat**。なめらか（Smooth）にしない。
- 面は 1 枚 1 色。細い面・とても小さい面を作らない（色を塗り分けにくく、遠くでちらつく）。目や鼻くらいの小さな部品は別。
- 頂点の重なりを消す: 編集モードで A → M → **By Distance**。
- 中に隠れた面・同じ所に 2 枚ある面は消す。
- 面の向き: Shift + N で外向きにそろえる。Face Orientation で赤がないか見る。
- **マイナスの大きさ（-1 倍）で反転しない**。面が裏返る。左右は Mirror で作る。
- 5 角形以上の面（N-gon）はくぼんだ形だと変に三角形に分かれる。気になる面は Ctrl + T で自分で三角形にしておく。

## 5. 色を塗る

テクスチャ（画像）は使わない。**面ごとに材質（マテリアル）を割り当てて色を付ける**。

### やり方
1. 材質のタブで、使う色の数だけ材質を作る。
2. **材質の名前を、パレットの色の名前にする**（下の表）。ゲームではこの名前を見て、パレットの色に置きかえる。
3. 編集モードで面を選び、材質を選んで Assign。
4. 見た目の確認用に、Base Color に下の色の値を入れておく（名前が合っていれば、値は多少ずれてもよい）。

### 猫に使う色（`src/style/palette.js`）
| 材質の名前 | 色 | 使う所 |
| --- | --- | --- |
| catOrange_0 | #C9732E | 暗いオレンジ（影になる所、模様） |
| catOrange_1 | #E89A4A | 毛の基本の色 |
| catOrange_2 | #F2B26A | 明るいオレンジ |
| catWhite_1 | #EDEBE6 | 口元・あご・胸・お腹・手・しっぽの先 |
| catWhite_2 | #F9F8F5 | 明るい白 |
| catPink_1 | #E79AA8 | 鼻、耳の内側、肉球 |
| eye | #1E1E22 | 目 |
| boots_0 | #4A2A1A | ブーツの底 |
| boots_1 | #5A3422 | ブーツ |
| boots_2 | #7A4A30 | ブーツの明るい面 |

- 「面ごとの明るさの揺らぎ（±4%）」はゲームの側で付けるので、Blender では付けなくてよい。
- 色を増やしたいとき（敵の色など）は、名前を決めてメモに書いておく。再開したら先にパレットに足す（色はパレットにしか置かないルール）。
- 1 体の材質は 10 個くらいまでにする。

## 6. 動かす部品に分ける（関節）

ゲームの猫は「部品ごとに関節で回す」作りになっている。それに合わせると、今の歩き・揺れの動きがそのまま使える。

### 部品の分け方と名前（英語の名前にする。日本語・空白は使わない）
| 名前 | 部品 | 原点（回る中心）の位置 |
| --- | --- | --- |
| root | 全体のまとめ（空のオブジェクト Empty） | 足もと (0, 0, 0) |
| torso | 胴 | 胴の下のほう |
| head | 頭（目・鼻を含めてよい） | 首の付け根（頭と胴の境目） |
| ear_L / ear_R | 耳 | 耳の付け根 |
| arm_L / arm_R | 腕（手・肉球を含む） | 肩 |
| leg_L / leg_R | 脚（ブーツを含む） | 脚の付け根 |
| tail_1〜tail_4 | しっぽを 3〜4 つに分けた節 | それぞれの節の付け根 |

- _L はキャラから見た左（正面図では画面の右側）、_R は右。
- 分け方: 編集モードで部品の面を選び、P → Selection で別のオブジェクトにする。
- **原点を関節に置く**: 関節の所の頂点を選んで Shift + S → Cursor to Selected。オブジェクトモードで右クリック → Set Origin → Origin to 3D Cursor。
- **親子にする**: 子を選んでから親を Shift で選び、Ctrl + P → Object（Keep Transform）。
  - root ← torso ← head ← ear_L, ear_R
  - torso ← arm_L, arm_R, tail_1 ← tail_2 ← tail_3 …
  - root ← leg_L, leg_R
- 部品ごとに **Ctrl + A → Rotation & Scale** で回転と大きさを確定する（位置は確定しない。原点が関節にあるため）。
- 部品の境目にすき間が見えないよう、関節の所は少し重ねる（回したときに穴が見えないように）。
- 1人称の画面に出す腕は、arm_R と同じ形を使う予定（別に作らなくてよい）。

### ボーン（アーマチュア）を使う場合
- 部品分けの代わりに、ボーンを入れて動きを Blender で付けることもできる。そのときは:
  - ボーンは 10〜20 本くらいまで。
  - **各部品を 1 本のボーンに 100% で割り当てる**（境目をぼかさない。ローポリらしいカクカクした動きになり、形も崩れない）。
  - 動き（アクション）の名前を idle / walk / run / attack / hurt / die などにする。
  - 書き出しで Animation をオンにする。
- 初めてなら、**部品分けのほうが簡単でおすすめ**。動きはゲームの側（コード）で付けられる。

## 7. 書き出す前の確認リスト

- [ ] 足の裏が Z = 0、体の中心が X = 0・Y = 0
- [ ] テンキー 1 の正面図で顔が見える
- [ ] 全高が決めた大きさ（猫は約 1.4m）
- [ ] 大きさは 1 倍のまま（オブジェクトの Scale がすべて 1.0。Ctrl + A で確定済み）
- [ ] Shade Flat になっている
- [ ] Face Orientation で赤い面がない
- [ ] 頂点の重なりを消した（Merge by Distance）
- [ ] 三角形の数が目安の中
- [ ] 材質の名前がパレットの色の名前
- [ ] 部品の名前が英語で、原点が関節にあり、親子になっている
- [ ] 参考画像・カメラ・ライト・使っていない物が残っていない（または書き出しで選ばない）
- [ ] Mirror モディファイアーは確定したか、書き出しで適用する設定

## 8. 書き出し（glTF / .glb）

1. 書き出す物（root とその子すべて）を選ぶ。root を右クリック → Select Hierarchy が楽。
2. File → Export → **glTF 2.0 (.glb/.gltf)**。
3. 設定:
   | 項目 | 設定 |
   | --- | --- |
   | Format | **glTF Binary (.glb)** |
   | Include → Limit to | **Selected Objects** をオン |
   | Include → Data | Cameras・Punctual Lights はオフ |
   | Transform | **+Y Up をオン**（初めからオン） |
   | Mesh | **Apply Modifiers をオン**。UVs はオフでよい。Normals はオン |
   | Material | Export |
   | Animation | 部品分けならオフ。ボーンで動きを付けたならオン |
   | Compression | オフ |
4. 名前は英語の小文字で: `cat.glb`、`enemy_slime.glb` など。
5. 置き場所: プロジェクトの中に `public/models/` というフォルダを作って、そこに置く。
   - 例: `C:\Users\yamas\oasobi5\public\models\cat.glb`
   - Blender の元のファイル（.blend）も、`models_src/cat.blend` のように残しておく（直すときに使う）。

### 書き出したあとの確認
- https://threejs.org/editor/ に .glb をドラッグすると、ゲームと同じ three.js で見られる。大きさ・向き・色・部品の名前（右の一覧）を確かめる。
- 向きが反対・横になっていたら、Blender で root を回して Ctrl + A で確定し、書き出し直す。

## 9. 再開したときのために書いておくメモ

`public/models/` に、モデルごとにメモを 1 つ置く（例: `public/models/cat.txt`）。これがあれば、再開したときにすぐゲームに入れられる。

```
名前: cat.glb
何か: 自キャラの猫
全高: 1.4m（足の裏 0、正面 -Y）
三角形の数: 約 700
部品: root, torso, head, ear_L, ear_R, arm_L, arm_R, leg_L, leg_R, tail_1〜tail_4
動き: なし（コードで付ける） / ボーンありなら アクション名の一覧
材質: catOrange_1, catWhite_1, catPink_1, eye, boots_1 …
新しく足したい色: （あれば名前と色の値）
気になっている所: （あれば）
```

敵ならさらに:
```
大きさ: 高さ ◯m、当たり判定の円の半径 ◯m
動き方の案: 例) ぴょんぴょん跳ねて近づく、体当たり
強さの案: 例) 弱い、HP 少なめ
出る場所の案: 例) 森、夜だけ
```

## 10. 敵キャラを作るときのコツ

- **形（シルエット）で見分けられるように**: 遠くから影だけ見ても何か分かる形にする。猫と同じくずんぐりした体型にすると世界に合う。
- **色**: 世界は落ち着いた自然色、キャラクターは明るい色（style.md）。敵は猫と区別できる色にする（例: 青・紫・赤み）。新しい色は名前を付けてメモに書く。
- **目**: 猫と同じく「小さな黒い四角」にすると、同じ世界の生き物に見える。
- **大きさ**: 小さい敵 0.5〜1m、ふつう 1〜1.6m、大きい敵 2〜4m くらい。建物の壁は高さ 2.5m、ドアは高さ 2.0m・幅 0.8m なので、ドアを通れる・通れないも決めておく。
- **当たり判定**: ゲームでは「縦の円柱」で当たりを調べる。円柱の半径と高さを決め、体がだいたいその中におさまる形にする。
- **動かす部品**: 6章と同じく、動く所を部品に分けて原点を関節に置く。動きが少ない敵（スライムなど）は 1 つの部品でもよい（伸び縮みはコードで付けられる）。
- **攻撃の見た目**: 攻撃に使う部分（腕、口、角など）は別の部品にしておくと、攻撃の動きが付けやすい。
- **面の数**: 敵は同時にたくさん出るかもしれないので、小さい敵は少なめ（150〜400）に。

## 11. よくある失敗

| 起きること | 原因 | 直し方 |
| --- | --- | --- |
| ゲームで巨大・極小になる | 単位が cm、または Scale が 1 でない | 単位を m に、Ctrl + A で Scale を確定 |
| 後ろ・横を向いている | 正面が -Y でない | root を回して確定、書き出し直し |
| 地面に埋まる・浮く | 足の裏が Z = 0 でない | 全体を動かして足の裏を 0 に |
| 一部の面が見えない（透ける） | 面が裏返っている | Shift + N、マイナスの Scale をやめる |
| 体の真ん中にすき間 | Mirror の Clipping がオフ | Clipping をオン、真ん中の頂点を X = 0 に |
| 腕を回すと肩の所がずれる | 原点が関節にない | 6章の手順で原点を置き直す |
| つるっとした見た目になる | Smooth のまま | Shade Flat |
| 色がおかしい | 材質の名前が違う | 5章の表の名前にする |
| ファイルにカメラやライトが入る | 全部を書き出した | Selected Objects で書き出す |
| 文字化け・読み込めない | 名前に日本語や空白 | 英語・数字・_ だけにする |

## 12. 練習の順番（おすすめ）

1. まず 1 時間で「ブロックアウトだけの猫」を作って書き出し、three.js editor で見る（向き・大きさの練習）。
2. 次に頭だけをていねいに作る（顔が一番目立つ）。
3. 胴・腕・脚・しっぽを作り、部品に分けて原点を置く。
4. 色を塗り、確認リスト（7章）を見て書き出す。
5. 慣れたら敵を 1 体（スライムのような単純な形から）。

調べるときの言葉: 「Blender low poly character」「Blender ローポリ キャラクター」「Blender Decimate symmetry」「Blender glTF export」。

## 13. 開発を再開したらやること（Claude 向け）
