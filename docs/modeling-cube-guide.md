# 立方体から猫を作る（1 操作ずつの手順）

[modeling-guide.md](modeling-guide.md) の「4. 形を作る」を、立方体を削って形にするやり方（ボックスモデリング）で、1 操作ずつ書いたもの。
数字はそのまま打ち込めば、ゲームの猫の大きさ（全高 1.4m）になる。

Blender の画面が日本語でも英語でも分かるよう、`日本語（English）` の形で書く。

---

## 第 0 章　始める前に（ここでつまずく人が多い）

### 0-1. ノートパソコンのとき（テンキー・中ボタンがない）
- 編集 → プリファレンス → 入力（Edit → Preferences → Input）
  - **テンキーを模倣（Emulate Numpad）** をオン → 上の数字キー 1・3・7 が「正面・横・上から見る」になる。
  - **3 ボタンマウスを模倣（Emulate 3 Button Mouse）** をオン → Alt + 左ドラッグで視点を回せる。
- 右上の色つきの丸（X・Y・Z の矢印、ナビゲーションギズモ）をクリックしても、その向きから見られる。

### 0-2. 視点の動かし方
| したいこと | 操作 |
| --- | --- |
| 回す | 中ボタンでドラッグ（または Alt + 左ドラッグ） |
| 横にずらす | Shift + 中ボタンでドラッグ |
| 近づく・離れる | ホイール |
| 選んだ物に寄る | テンキーの .（ピリオド）（View → Frame Selected） |
| 正面・右横・上 | 1・3・7（Ctrl を足すと背面・左横・下） |

### 0-3. 困ったとき
- **Ctrl + Z で元に戻す**。何回でも戻せる。おかしくなったら、まず Ctrl + Z。
- 物全体が動いてしまう → **オブジェクトモードになっている**。Tab で編集モードにする。
- 頂点が選べない・裏の頂点が選べない → **Alt + Z（透過表示）** をオンにする。
- 何かキーを押して変な画面になった → Esc か右クリックで、今の操作を取り消せる。
- 画面の左下に出る小さな箱（**最後の操作を調整**、Adjust Last Operation）で、直前の操作の数値をあとから変えられる。とても便利。

### 0-4. 数字で動かす（大事）
G・S・R のあとに、**軸の文字 → 数字 → Enter** と打つと、ぴったり動かせる。
- `G Z 0.1 Enter` … 上へ 0.1m 動かす
- `G Y -0.05 Enter` … 前（-Y）へ 0.05m 動かす（**猫の正面は -Y**）
- `S X 1.2 Enter` … 横（X）だけ 1.2 倍にする
- `S Z 0 Enter` … 高さを 0 倍 = 選んだ頂点を同じ高さにそろえる（平らにする）
- `R Y 20 Enter` … Y 軸で 20 度回す

### 0-5. 選び方
| 選び方 | 操作 |
| --- | --- |
| 1 つ選ぶ | 左クリック |
| 足す・外す | Shift + 左クリック |
| 輪っか状に一周選ぶ（ループ） | **Alt + 左クリック**（辺の上で） |
| 四角で囲んで選ぶ | 左ドラッグ（または B） |
| 筆で塗るように選ぶ | C（ホイールで大きさ、右クリックで終わる） |
| つながった部分を全部 | マウスを乗せて L |
| 全部選ぶ・外す | A ／ Alt + A |
| 選んでいない方を選ぶ（反転） | Ctrl + I |

編集モードでは、キーボードの **1 = 頂点、2 = 辺、3 = 面** を選ぶモードに切り替わる（テンキーではなく、上の数字キー）。
※「テンキーを模倣」をオンにした場合は、画面左上の 3 つのボタン（頂点・辺・面）で切り替える。

## 第 1 章　頭（いちばん大事。ここで基本の操作を全部覚える）

### 1-1. 立方体を置いて、大きさを決める
1. オブジェクトモードで `Shift + A` → メッシュ → 立方体（Mesh → Cube）。
2. `N` で右側に「サイドバー」を出す。「アイテム」タブ（Item）に数字を打つ:
   - 位置（Location）: X `0`、Y `0`、Z `1.0`
   - 寸法（Dimensions）: X `0.5`、Y `0.45`、Z `0.45`
3. `Ctrl + A` → **スケール（Scale）** を選ぶ。拡大率を 1 に確定する（これをしないと、あとで形がゆがむ）。
4. 名前を変える: 右上の一覧（アウトライナー）で立方体をダブルクリック → `head` と打つ。

### 1-2. 面を細かくする（削るための「切れ目」を入れる）
1. `Tab` で編集モード。`A` で全部選ぶ。
2. 右クリック → **細分化（Subdivide）**。
3. 左下の「最後の操作を調整」を開いて、**分割数（Number of Cuts）を `3`** にする。
   - 立方体の 1 つの面が 4 × 4 のマス目になる。
   - 3 にするのは、**真ん中（X = 0）に線ができる**から（左右対称に作るのに必要）。

### 1-3. 丸くする（立方体 → 丸い頭）
1. `A` で全部選んだまま、`Shift + Alt + S`（**球状に変形、To Sphere**）。
2. マウスを動かすか、`0.8` と打って Enter。
   - 1 にすると完全な球、0 だと立方体のまま。**0.7〜0.85** くらいが、少し角の残った猫の頭らしい形。
3. この時点で、四角い面が並んだ「丸っこい箱」になっていれば OK。

### 1-4. 左右対称にする（半分を消して、ミラーを付ける）
1. テンキー `1`（正面から見る）。`Alt + Z` で透過表示をオン。
2. `1` で頂点モード。**画面の左半分（X がマイナスの側）の頂点**を、左ドラッグの四角で囲んで選ぶ。
   - 真ん中の縦の列（X = 0）は**選ばない**。
3. `X` → **頂点（Vertices）** で消す。右半分だけが残る。
4. 右側のプロパティの「モディファイアー」タブ（青いスパナ）→ 追加（Add Modifier）→ 生成（Generate）→ **ミラー（Mirror）**。
5. 軸（Axis）は **X** がオンになっていることを確かめる。**クリッピング（Clipping）をオン**。
6. 左右そろった頭が見えれば OK。ここから先は**右半分だけをいじれば、左にも同じ変化が付く**。

> 注意: 真ん中の列の頂点は、X = 0 から動かさない（クリッピングがオンなら勝手に止まる）。

### 1-5. 形を整える（頬・口元・頭の上）
**プロポーショナル編集**を使うと、粘土のように「周りも一緒に、なめらかに」動く。
- `O` でオン・オフ（画面上の丸い的のアイコンが青くなる）。
- G・S の途中で**ホイールを回すと、影響する範囲（円）が変わる**。

1. **頭の上を少し平らに**: 正面図（`1`）で、一番上の頂点の行を四角で囲んで選ぶ → `S Z 0 Enter` → `G Z -0.02 Enter`。
2. **頬をふくらませる**: 正面図で、下半分の外側（右端）の頂点を 2〜3 個選ぶ → `O` でプロポーショナルをオン → `G X 0.03 Enter`（範囲はホイールで、頭の 1/3 くらいの円に）。
3. **口元を前に出す**: 横から見る（`3`）。前（画面の左、-Y 側）の、下から 2 段目あたりの頂点を、真ん中の列も含めて選ぶ → `G Y -0.04 Enter`。
   - 正面図で見て、鼻と口のあたりが前に出ていれば OK。
4. **あごを少し引く**: 一番下の前側の頂点 → `G Y 0.02 Enter`。
5. プロポーショナルを `O` でオフに戻す（付けたままだと、あとの操作で周りまで動いてしまう）。

### 1-6. ローポリらしくする（角ばった、不ぞろいな三角形にする）
ここまでだと「四角いマス目」が規則正しく並んでいる。これを、形に沿った不ぞろいな三角形にする。

**やり方 1: ナイフで切って、いらない辺を消す（手作業。きれい）**
1. `K`（**ナイフ**）。頂点から頂点へクリックしていくと、その間に辺が入る。Enter で確定。
   - 頬のふくらみの所に、斜めに辺を入れる。目の下から口元へ向かう斜めの線、など。
   - **手前と奥を同時に切る**: ナイフの途中で `Z` を押す（貫通、Cut Through）。画面の一番下の説明に、貫通（Cut Through）がオンと出る。奥に隠れた面にも同じ線が入る。
   - **ぴったりまっすぐ全体を切る**: 編集モードで `A` で全部選び、画面の上のメニュー メッシュ → 二等分（Mesh → Bisect）。ドラッグした線で、物全体を板で切ったように切れ目が入る。
2. 目立たない所（後頭部など）の辺は、`2`（辺モード）で選んで `X` → **辺を溶解（Dissolve Edges）**。面がまとまって大きくなる。
3. 「形が曲がっている所は細かく、平らな所は大きく」を意識する。

**やり方 2: まとめて減らす（自動。速い）**
1. モディファイアーを追加 → 生成 → **デシメート（Decimate）**。
2. **ミラーより下に置く**（モディファイアーの一覧で、ミラーの下にあること）。
3. 「束ねる（Collapse）」のまま、**比率（Ratio）** を下げる（0.5〜0.7 くらい）。
4. **対称（Symmetry）をオン**、軸は X。
5. 統計（Statistics）を見ながら、頭の三角形が **100〜250** くらいになるようにする。

※ どちらでも、最後に **右クリック → フラットシェード（Shade Flat）** をしておく（オブジェクトモードで）。

### 1-7. 目と鼻
- **目**: オブジェクトモードで `Shift + A` → 立方体。寸法 X `0.04`、Y `0.02`、Z `0.05`。正面図で、頭の真ん中より少し上、真ん中から X `0.1` の所に置き、横から見て頭の表面に少し埋まる位置まで `G Y` で動かす。
  - 左右 2 つ作る代わりに、目にもミラーを付けると楽（ミラーの「ミラーオブジェクト」に何も入れなければ、自分の原点で反転する。原点を X = 0 に置いておく）。
  - 名前は `eye`。あとで頭（head）の子にする。
- **鼻**: 円すい（Cone）、頂点（Vertices）`3`、寸法を小さく（0.05 くらい）。先を下に向けて（`R X 180`）、目の間の少し下に置く。名前は `nose`。

### 1-8. 耳（面を押し出して作る練習）
耳は、頭とは**別の部品**にしたい（動かすため）。でも作り方の練習として、頭の面から押し出して作り、あとで切り離す。

1. 頭を編集モードにして、`3`（面モード）。頭の上の、外側寄りの面を **1 枚** 選ぶ（右半分の側。左はミラーで付く）。
2. `I`（**面を差し込む、Inset**）→ `0.01` と打って Enter。面の内側に、ひと回り小さい面ができる。
3. `E`（**押し出し、Extrude**）→ `0.15` と打って Enter。面が上に伸びる。
4. `S 0.15 Enter`。先が細くなって、三角すいのようになる。
5. `R Y 15 Enter`（外へ少し開く）。`G X 0.02 Enter` などで位置を整える。
6. **切り離す**: 耳の面を全部選ぶ（耳の上で `L`）→ `P` → **選択（Selection）**。耳が別のオブジェクトになる。今いじっているのは +X 側（正面図で画面の右）＝ キャラから見て左なので、名前は `ear_L`。
   - 切り離した耳には、ミラーが付いていない。耳にもミラーを付けて、**ミラーオブジェクトに `head` を選ぶ**と、頭の中心で反転した反対の耳ができる。書き出すときに「左右別のオブジェクト」が必要なら、ミラーを適用（Apply）してから `P` → 「構造的に分離（By Loose Parts）」で分け、名前を `ear_L` と `ear_R` にする。
7. 耳の内側のピンク: 耳の前の面を選び、材質 `catPink_1` を割り当てる（第 6 章）。

## 第 2 章　胴（同じやり方の復習）

1. オブジェクトモードで `Shift + A` → 立方体。位置 Z `0.55`。寸法 X `0.55`、Y `0.5`、Z `0.6`。`Ctrl + A` → スケール。名前 `torso`。
2. `Tab` → `A` → 右クリック → 細分化 → 分割数 `3`。
3. `Shift + Alt + S` → `0.7`。
4. 正面図で左半分の頂点を消し、ミラー（X、クリッピング）を付ける。
5. **下を太く（卵形に）**: 正面図で下から 2 行の頂点を選ぶ → `S X 1.15 Enter` → `S Y 1.1 Enter`。
6. **上を細く**: 上から 2 行 → `S X 0.85 Enter`。
7. **底を平らに**: 一番下の行 → `S Z 0 Enter`。
8. 頭と少し重なる高さか確かめる（頭の下端が胴の上端に 0.03m くらい埋まっているとよい。すき間があると首が見える）。
9. 1-6 と同じように、ローポリらしくする（胴は 60〜150 三角形）。
10. **お腹の白**: 正面の、胸からお腹にかけての面を `C`（筆選び）で塗るように選び、材質 `catWhite_1` を割り当てる。

## 第 3 章　腕（「角を落とす」= ベベルで八角形にする）

立方体の角を削ると、八角形の柱になる。腕・脚・しっぽに使う。

1. `Shift + A` → 立方体。寸法 X `0.14`、Y `0.14`、Z `0.3`。`Ctrl + A` → スケール。名前 `arm_L`。
2. `Tab` → `2`（辺モード）。**縦の 4 本の辺**を、`Shift + クリック` で選ぶ（`Alt + Z` で透過すると裏も選べる）。
3. `Ctrl + B`（**ベベル、Bevel**）→ マウスを少し動かして、`0.03` と打って Enter。
   - 左下の「最後の操作を調整」で、**セグメント（Segments）が 1** になっていること。
   - 上から見ると（`7`）、四角の角が落ちて**八角形**になっていれば OK。
4. **ループカット**で横に切れ目を入れる: `Ctrl + R` → 腕の上にマウスを乗せると黄色い輪が出る → ホイールで本数を `2` に → 左クリック → 右クリック（真ん中に入る）。
5. **先を手の形にふくらませる**: 一番下の輪の頂点を `Alt + クリック` で選ぶ → `S 1.25 Enter`。
6. **少し曲げる**: 真ん中の輪を選ぶ → `G Y -0.02 Enter`（前に少し出る）。
7. 手の白: 下の 2 段の面を選んで `catWhite_1`。手のひら側（前・下）の面 1〜2 枚に `catPink_1`（肉球）。
8. **原点を肩に置く**（第 7 章でまとめてやってもよい）: 一番上の頂点を全部選ぶ → `Shift + S` → **カーソル → 選択物（Cursor to Selected）** → `Tab` でオブジェクトモード → 右クリック → **原点を設定 → 原点を 3D カーソルへ（Set Origin → Origin to 3D Cursor）**。
9. 位置: X `0.24`、Z `0.72` あたり（肩が胴の横に少し埋まる位置）。少し前に出す（Y `-0.05`）。
10. 反対の腕: オブジェクトモードで `Shift + D`（複製）→ `S X -1 Enter` は**しない**（裏返る）。代わりに複製して `G X` で反対側へ動かし、`R Z 180` で向きを合わせるか、ミラー（ミラーオブジェクト = `torso`）を付けて適用してから分ける。名前 `arm_R`。

## 第 4 章　脚とブーツ

1. **脚**: 第 3 章と同じ八角形の柱。寸法 X `0.15`、Y `0.15`、Z `0.2`。名前 `leg_L`。
2. **ブーツ**: 立方体。寸法 X `0.17`、Y `0.24`、Z `0.13`。底が Z `0` に来るように置く。前（-Y）に少し長く。
   - `2` で、前の上の横の辺を 1 本選び → `Ctrl + B` → `0.03`（つま先の角を少し丸める）。
   - 底の面は `boots_0`、ほかは `boots_1`、明るい面を何枚か `boots_2`。
3. ブーツと脚を 1 つにまとめる: 両方選んで（脚を最後に選ぶ）`Ctrl + J`（**結合、Join**）。
4. 原点を脚の付け根（上の端）に置く。位置 X `0.11`、付け根の高さ Z `0.29`。
5. 反対の脚 `leg_R` を作る（腕と同じやり方）。

---

## 第 5 章　しっぽ（押し出しを続けて曲げる）

1. 立方体。寸法 X `0.12`、Y `0.12`、Z `0.12`。第 3 章のベベルで八角形にする（今回は 4 本の**前後方向**の辺。しっぽは後ろへ伸びるので）。
   - 簡単にするなら、`R X 90 Enter` で寝かせてから縦の辺をベベルしてもよい。
2. 位置: X `0`、Y `0.22`（後ろ）、Z `0.36`。
3. `Tab` → `3`（面モード）→ **後ろ（+Y）の面**を 1 枚選ぶ。
4. `E` → `Y` → `0.12` Enter（後ろへ伸びる）。
5. もう一度 `E` → `0.12` Enter → `R X -25 Enter`（上へ曲がり始める）。
6. 同じことを 2〜3 回くり返す。回すたびに上を向いていく。
7. 最後の面を `S 0.8 Enter` で少し細くし、先の 1 段の面を `catWhite_1` に。
8. ゲームでは、しっぽを 3〜4 つの節（`tail_1`〜`tail_4`）に分けると揺らせる。分けるときは、節の境目から先の面を選んで `P` → 選択。各節の原点を、その節の付け根に置く。
9. しっぽは左右対称でなくてよい（少し横に曲げると、かわいい）。

## 第 6 章　色を塗る（材質を面に割り当てる）

1. 部品を選んで、プロパティの「マテリアル」タブ（赤い球）。
2. 「＋」でスロットを増やし、「新規（New）」で材質を作る。名前を `catOrange_1` などにする（[modeling-guide.md](modeling-guide.md) の 5 章の表）。
3. **ベースカラー（Base Color）** に色の値を入れる（例 `E89A4A`）。
4. 2 つ目以降の材質も同じように作る。**別の部品で同じ色を使うときは、新しく作らず、一覧から同じ材質を選ぶ**（名前の後ろに .001 が付いたら作り直し）。
5. 編集モードで、塗りたい面を選ぶ → 材質の一覧でその材質を選ぶ → **割り当て（Assign）**。
6. 画面右上の「ビューポートシェーディング」の 3 つ目（マテリアルプレビュー）か 2 つ目（ソリッド）で色を確認。ソリッドの場合は、シェーディングの設定で「カラー → マテリアル」にすると見える。

## 第 7 章　部品をつなぐ（原点・親子）

1. 各部品の原点を関節に置く（3-8 のやり方）。

   | 部品 | 原点の位置（目安） |
   | --- | --- |
   | head | 頭の下の端の真ん中（X 0、Z 約 0.78） |
   | ear_L / ear_R | 耳の付け根 |
   | arm_L / arm_R | 肩（Z 約 0.72） |
   | leg_L / leg_R | 脚の付け根（Z 約 0.29） |
   | torso | 胴の下の真ん中（X 0、Y 0、Z 約 0.3） |
   | tail_1… | それぞれの節の付け根 |

2. `Shift + A` → **エンプティ → 十字（Empty → Plain Axes）** を (0, 0, 0) に置き、名前を `root` にする。
3. 親子にする: **子を先に選び、最後に親を Shift + クリック** → `Ctrl + P` → **オブジェクト（トランスフォーム維持）（Object (Keep Transform)）**。
   - `torso` → 親 `root`
   - `head` → 親 `torso`、`ear_L`・`ear_R`・`eye`・`nose` → 親 `head`
   - `arm_L`・`arm_R`・`tail_1` → 親 `torso`、`tail_2` → 親 `tail_1` …
   - `leg_L`・`leg_R` → 親 `root`
4. **試しに回す**: `head` を選んで `R X 20` → 首の所で自然に回るか見る → `Ctrl + Z` で戻す。腕・脚・耳も同じように確かめる。おかしな所で回るなら、原点の位置がずれている。

## よくあるつまずき（この手引きの操作で）

| こうなった | 原因と直し方 |
| --- | --- |
| 細分化したのに真ん中に線がない | 分割数が偶数（2 など）。`Ctrl + Z` で戻して **3** に |
| 球状に変形で、ぐちゃっとつぶれた | 一部しか選んでいなかった。`Ctrl + Z` → `A` で全部選んでからもう一度 |
| ミラーの真ん中にすき間・重なり | クリッピングがオフ、または真ん中の頂点を消してしまった。真ん中の列を残してやり直す |
| ミラーで左右が逆向き・2 重 | 消す側を間違えた（右を消した）。それでも見た目は同じなので、気にしなくてよい。2 重に見えるなら、消し残しの頂点がある |
| 押し出し（E）で面が変な向きに伸びた | `E` のあと、軸の文字（`Z` など）を打つと、その向きにだけ伸びる |
| ベベルで角が丸くなりすぎた | 左下の「最後の操作を調整」でセグメントを 1 に、幅を小さく |
| 拡大したら、ほかの部分もゆがむ | `Ctrl + A` → スケール をしていない。オブジェクトモードでする |
| プロポーショナル編集が効きすぎる | G・S の途中でホイールを回して、円を小さく。使い終わったら `O` でオフ |
| `Shift + D` で複製したら、どこかへ飛んだ | 複製のあと、マウスに付いて動いている。右クリックで「その場に置く」 |
| 間違えて頂点を消した | `Ctrl + Z` |
