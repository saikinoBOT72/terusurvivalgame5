# 武器と戦い方（2026-10-17 決定）

プレイヤーの攻撃・守り・遠距離武器の決まり。敵の側は `enemies.md`「戦闘」。数値は**表だけ**に書く（武器は `src/survival/items.js`、素手は `HAND`）。武器を増やすときは表に 1 行足すだけで動くようにする。下の数は始めの値で、遊びながら表で直す。

## 近接武器の項目（items.js）

| 項目 | 意味 | なければ |
| --- | --- | --- |
| `dmg.mob` | 敵への攻撃力（`dmg.drone` のように敵の名前があれば、その敵にはそちら） | 素手と同じ |
| `swing` | 1 回振る秒数 | 0.4 |
| `reach` | 届く m | 2.5 |
| `knock` | 当てた敵がのけぞる秒数 | 0.3 |
| `hit` | 当たり方。`'thrust'` 照準の線で 1 体（やり・ナイフ・素手）、`'arc'` 前 90 度・届く距離の中の全部（斧・ピッケル） | `'thrust'` |
| `stam` | 1 回振るスタミナ | 6 |
| `heavy` | ため攻撃 `{ hold: 満タンまでの秒, mult: 攻撃力とのけぞりの倍率 }` | `{ hold: 0.8, mult: 2 }` |

## スタミナ・ステップ・ため・ガード

- **スタミナ**: 100。使わずに 0.8 秒たつと 1 秒に 30 戻る。振る（武器の `stam`）、ステップ 25、ため攻撃は振るの 2 倍、ガードで受けたダメージの分だけ減る。**0 のときはステップ・ため攻撃・ガードができない**（ふつうに振るのはできる）。
- **ステップ**: 地上で **C ＋ 移動キーの向き**（キーなしなら後ろ）へ 0.2 秒で 1.8m 動く。その 0.2 秒は攻撃を受けない。水の中・乗り物の上ではできない。
- **ため攻撃**: 左を押し続けると力がたまり、`heavy.hold` 秒で満タン。離すと振る。満タンなら攻撃力とのけぞりが `heavy.mult` 倍。短く押したとき（0.2 秒まで）はふつうの攻撃。ためている間は歩く速さが半分。手の道具が少し後ろへ引かれ、満タンで小さく震える。
- **ガード**: 近接武器を持って**右クリックを押している間**。前（左右 60 度）から受けるダメージが半分になり、減った分はスタミナから引く。歩く速さ半分。盾は後で「受ける量が増える道具」として足す。
- **受け流し**: 敵の攻撃が当たる直前 0.2 秒以内に構え始めると、ダメージ 0 で敵が 1.5 秒崩れる（隙のポーズ。なければためのポーズ）。

## 受けたとき（プレイヤー）

- 受けたあと **0.5 秒は次の攻撃を受けない**（無敵の時間）。
- 攻撃ごとの `push`（m、`mobTypes.js`）の **2 倍**だけ、攻撃の来た向きへ 0.3 秒で押される（2026-10-17 大きくした。倍率は `STAM.push`）。攻撃に `pushSecs` があればその秒で、`lift`（m/秒）があれば上へも浮く（吹き飛ばし。ブンブンのつむじ風）。
- 敵の弾（風の弾）も同じ。ガードで半分、受け流すと弾が消える（敵は崩れない）。
- **続けて当たる攻撃（2026-10-17、犬の連続かみつき）**: 同じ攻撃の 2 回目（表の `combo`）は無敵の時間を無視して当たる。泥飛ばしのように一度に何個も飛ぶ弾は、無敵の時間があるので当たるのは 1 つまで。
- **泥が当たったとき（2026-10-17）**: 画面のふちに泥がつき、2 秒で薄れて消える（ui.md「泥」）。ガードで受けると泥はつかない。**鈍足**（攻撃の `slow: [倍率, 秒]`。泥は歩く速さ 0.5 倍を 3 秒）: ガードで受けなかったときだけ。ため・ガード・覗き込みの 0.5 とは重ならず、小さいほうになる。鈍足の間は画面のふちの泥をうすく残す。
- 画面が揺れる（攻撃力で重さが変わる。下の「受けたときの揺れの重さ」）。視点も少し上へはねる。自分が当てたときは揺らさない。
- 攻撃の来た向きを画面の端に赤い弧で出す（1 秒で消える）。

## 当てたときの手ごたえ（敵）

- 当たった敵は 0.1 秒白く光る。
- 当たった所から火花（黄色の短い線 6〜10 本）と小さい金属片が飛ぶ。弱点はもっと多く。
- 照準が一瞬 × になる（0.15 秒）。弱点なら大きく赤い ×。
- ダメージの数字が当たった所から浮いて 0.8 秒で消える。白、弱点は黄色で大きく。
- 撃墜: 部品が 3〜5 個はじけ飛び、煙を出しながら落ちる。2 秒後に部品（落とす物）を落として消える。

## 遠距離武器（スリング → 銃）

すべて同じ仕組み（飛ぶ弾）で動き、項目 `ranged` の値だけが違う。**遠距離は最強にしない**: 遠いほどばらつきで当たりにくく、距離で弱くなる。弾は物として飛び、重力で落ち、目に見える。

| 項目 | 意味 |
| --- | --- |
| `ammo` | 使う弾の物（石、ガラクタ弾） |
| `dmg` | 攻撃力（満タンまで引いたとき・1 発） |
| `speed` | 弾の速さ（m/秒） |
| `drop` | 重力の効き方（1 = ふつう、0 = まっすぐ） |
| `spread` | ばらつき（度）`[止まって, 動いて, 覗いて]` |
| `draw` | 引く秒数（スリング。引いた分で速さと攻撃力が 40%〜100%）。0 なら押してすぐ撃つ |
| `rate` | 次を撃てるまでの秒 |
| `mag` / `reload` | 弾倉の数と込め直しの秒（銃）。なければ 1 発ずつ持ち物から |
| `falloff` | 距離の減り方 `[ここまで 100%, ここで最小, 最小の倍率]` |
| `recoil` | 撃ったときに視点が上へはねる角度（度）。0.2 秒で戻る |
| `aim` | 右クリックで覗き込めるか。覗くと視野が 0.75 倍、歩く速さ半分 |

| 武器 | 攻撃力 | 速さ | ばらつき | 引く・連射 | 弾倉・込め直し | 減り方 |
| --- | --- | --- | --- | --- | --- | --- |
| スリング | 5 | 28 | 1.5° / 4° / - | 引く 1 秒 | 1 発ずつ（石） | [12m, 30m, 30%] |
| ガラクタ拳銃 | 10 | 90 | 1° / 3° / 0.4° | 連射 0.4 秒 | 6 発・R で 2.2 秒 | [10m, 35m, 35%] |

- **ガラクタ弾の見た目**（2026-10-17）: 銅の薬きょう 5 本を丸く並べて、さびた鉄のバンドで束ねた形（幅 約 7cm・高さ 約 6cm）。先は鉄のとがり。手に持つ・落ちている・アイコンとも同じ形（極小の目安）。
- 弾は敵・ヤシの実・鳥の巣・地形・木・岩・建築パーツに当たる。当たらなかったスリングの石はそのまま消える。
- 弾数は画面の右下に「4/6」のように出す（銃だけ）。
- 込め直しは R（建築中の R は今までどおり回す）。込め直しの途中で持ち替えると取りやめ。

## 武器の動きと演出（2026-10-17 決定。PLAN.md「戦闘の演出」）

手の動きは `src/avatar/fpMotion.js`（武器ごとのポーズの表）、手の組み立ては `src/avatar/fpHands.js`、銃の動きは `src/avatar/fpGun.js`。

- **3 段の振り**: 構え（ため・グッ: ゆっくり入って一瞬止まる）→ 振り（放出・バッ: 速く出て止まる）→ 戻り（ゆっくり）。当たりの判定は振りの終わり（武器ごとの割合）。振りの途中で次を振るときは、今のポーズから 0.08 秒でつなぐ（飛ばない）。
- **ため攻撃**: ためている間に、ため攻撃の構え（大きく引く・頭の上まで振りかぶる）へ少しずつ入り、満タンで震える。離すと構えを飛ばしていきなり振る。
- **当てた・外した**: 当てたら振りが一瞬止まり（0.05 秒、重い武器ほど長く 0.09 秒まで）、手と道具が振りと逆へ跳ね返る（重い武器ほど大きく）。外したら振りの向きへ少し振り抜けてから戻る。
- **重さ**: 武器の `stam` から（12 で 1）。重いほど 振り抜け・跳ね返り・歩く揺れが大きい。
- **歩く・見回す**: 歩くと武器が 8 の字に揺れる（遅く歩く間は小さく。走るができたら大きく）。視点を回すと手が少し遅れてついてくる。
- **持ち替え**: 新しい物は画面の下から 0.2 秒で出てくる。

| 武器 | 振り | ため攻撃 |
| --- | --- | --- |
| やり | 後ろへ引いて一気に突き出し、戻す。続けて（1 秒以内）突くと左右に少し角度を変える | 大きく引いて、体ごと（両手とも）前へ突き出す |
| 斧・ピッケル・ハンマー・その他の持ち物 | 右上へ振りかぶり、左下へ斜めに振り下ろす | 頭の上まで振りかぶって真下へ |
| ナイフ（剣ができたら同じ動き） | 横なぎ（右 → 左）と返し（左 → 右）を交互に。刃を寝かせる。速い | 右へ大きくひねって、強い横なぎ |
| 素手 | 左右の手で交互にまっすぐパンチ | 右手を大きく引いて強いパンチ |
| スリング | 引くほど手が後ろ・下へ下がり、震えが大きくなる。放つと前へ振り出す | - |

- **振りの軌跡**: 近接武器（素手は除く）を振ると、刃先の通り道に白い帯（`P.fx.swing`）が 0.15 秒残る。ため攻撃は太く、0.22 秒。新 `src/combat/swingFx.js`。
- **ガード**: 武器を横に寝かせて顔の前に構え、左手で支える。**ガード中は攻撃できない**（ためも始めない。ため中にガードしたらためを取りやめ）。受けると腕が後ろへはじかれる（受けた攻撃力ほど大きく）。受け流しは武器の前に白い閃光と火花（`P.fx.swing`・`P.fx.spark`）。
- **銃（ガラクタ拳銃は回転式なので、スライド＝撃鉄、弾倉＝回転弾倉）**: 撃つと上へはね、少し下がって戻る。撃鉄が後ろへ倒れて戻り、弾倉が 1/6 回る（弾切れでは撃鉄が倒れたまま）。**リロード**（込め直しの秒に合わせる）: 銃を傾けて下げる（0〜15%）→ 左手で弾倉を横へ抜いて画面の下へ（15〜40%）→ 新しい弾倉を持って上がり、差し込む（40〜70%）→ 左手で撃鉄を起こす（70〜90%）→ 構え直す（90〜100%）。覗き込みは今どおり。
- **銃の軌道**: 弾の玉は見せない（飛び方・重力・ばらつき・当たり方は今のまま）。撃った瞬間に、同じ飛び方で先に当たる所を調べ、銃口からそこまで光る線（芯 `P.fx.tracer[0]`・ふち `[1]`）を引く。線は 0.1 秒で細くなって消え、薄い煙の筋（`P.fx.tracerSmoke`）が 0.5 秒残って少し広がる。最長 120m。スリングの石は今どおり見せる。

## 攻撃間隔（マイクラ風。2026-10-17 決定）

武器ごとの `cd`（振ってから次を振れるまでの秒）。**満ちるまで次を振れない**。なければ `swing` と同じ。照準の下の線（ui.md「戦闘の表示」）で見せる。斧・ピッケルで木や岩を叩くときも同じ。遠距離武器は `rate`（連射の間隔）と込め直しを同じ線で見せる。

| 武器 | cd |
| --- | --- |
| 素手 | 0.4 |
| ナイフ | 0.5 |
| やり | 0.7 |
| 斧 | 0.9 |
| ピッケル | 1.0 |

## 受けたときの揺れの重さ（2026-10-17 決定。上の「受けたとき」の揺れを置きかえる）

揺れ方は**受けた攻撃の攻撃力**（ガードで減る前）で決める。間は線でつなぐ。

| 攻撃力 | 大きさ | 秒 | 速さ（1 秒に揺れる回数） | 視点の横の傾き |
| --- | --- | --- | --- | --- |
| 10 | 0.06 | 0.25 | 22 | 0 |
| 30 | 0.14 | 0.4 | 14 | 0.04 ラジアン |
| 50 | 0.24 | 0.6 | 8 | 0.09 ラジアン |

- ガードで受けたときは大きさ半分。手も少し後ろへはねる。
