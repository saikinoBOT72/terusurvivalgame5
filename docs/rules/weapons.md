# 武器と戦い方（2026-10-17 決定）

プレイヤーの攻撃・守り・遠距離武器の決まり。敵の側は `enemies.md`「戦闘」。数値は**表だけ**に書く（武器は `src/survival/items.js`、素手は `HAND`）。武器を増やすときは表に 1 行足すだけで動くようにする。下の数は始めの値で、遊びながら表で直す。

## スタミナ・ステップ・ため・ガード

- **スタミナ**: 100。使わずに 0.8 秒たつと 1 秒に 30 戻る。振る（武器の `stam`）、ステップ 25、ため攻撃は振るの 2 倍、ガードで受けたダメージの分だけ減る。**0 のときはステップ・ため攻撃・ガードができない**（ふつうに振るのはできる）。
- **走る・泳ぐのスタミナ**（2026-10-19。player.md「動き方」「泳ぐ」）: 走ると 1 秒に 6（満タンから約 17 秒）、泳ぐと 1 秒に 4・浮いているだけ 1.5・速く泳ぐ 10。使っている間は戻らない（使い終わって 0.8 秒たつと戻る）。**0 になったら走れなくなり、20 たまるまで走れない**。泳いでいて 0 になると浮けなくなり沈む。7（装備）の「スタミナ上昇」はこの最大値を上げる。
- **ステップ**: 地上で **X（初期値。キー設定で変えられる）＋ 移動キーの向き**（キーなしなら後ろ）へ 0.2 秒で 1.8m 動く。その 0.2 秒は攻撃を受けない。水の中・乗り物の上ではできない。
- **ため攻撃**: 左を押し続けると力がたまり、`heavy.hold` 秒で満タン。離すと振る。満タンなら攻撃力とのけぞりが `heavy.mult` 倍。短く押したとき（0.2 秒まで）はふつうの攻撃。ためている間は歩く速さが半分。手の道具が少し後ろへ引かれ、満タンで小さく震える。
- **ガード**: 近接武器を持って**右クリックを押している間**。前（左右 60 度）から受けるダメージが半分になり、減った分はスタミナから引く。歩く速さ半分。盾は後で「受ける量が増える道具」として足す。
- **掘る道具（斧・ピッケル。2026-10-21）**: ため攻撃とガードはなし。**左を押し続けると、攻撃間隔が満ちるたびに振りつづける**。右クリックはふつうの「使う」（狙った物を開ける・拾うなど）。やり・ナイフは今までどおり。
- **受け流し**: 敵の攻撃が当たる直前 0.2 秒以内に構え始めると、ダメージ 0 で敵が 1.5 秒崩れる（隙のポーズ。なければためのポーズ）。

## 受けたとき（プレイヤー）

- 受けたあと **0.5 秒は次の攻撃を受けない**（無敵の時間）。
- 攻撃ごとの `push`（m、`mobTypes.js`）の **2 倍**だけ、攻撃の来た向きへ 0.3 秒で押される（2026-10-17 大きくした。倍率は `STAM.push`）。攻撃に `pushSecs` があればその秒で、`lift`（m/秒）があれば上へも浮く（吹き飛ばし。ブンブンのつむじ風）。
- 敵の弾（風の弾）も同じ。ガードで半分、受け流すと弾が消える（敵は崩れない）。
- **続けて当たる攻撃（2026-10-17、犬の連続かみつき）**: 同じ攻撃の 2 回目（表の `combo`）は無敵の時間を無視して当たる。泥飛ばしのように一度に何個も飛ぶ弾は、無敵の時間があるので当たるのは 1 つまで。
- **泥が当たったとき（2026-10-17）**: 画面のふちに泥がつき、2 秒で薄れて消える（ui.md「泥」）。ガードで受けると泥はつかない。**鈍足**（攻撃の `slow: [倍率, 秒]`。泥は歩く速さ 0.5 倍を 3 秒）: ガードで受けなかったときだけ。ため・ガード・覗き込みの 0.5 とは重ならず、小さいほうになる。鈍足の間は画面のふちの泥をうすく残す。
- 画面が揺れる（攻撃力で重さが変わる。下の「受けたときの揺れの重さ」）。視点も少し上へはねる。自分が当てたときは揺らさない。
- 攻撃の来た向きを画面の端に赤い弧で出す（1 秒で消える）。

## 当てたときの手ごたえ（敵）

- 当たった敵は 0.1 秒白く光る。
- 当たった所から火花（黄色の短い線 6〜10 本）と小さい金属片が飛ぶ。弱点はもっと多く。
- 照準が一瞬 × になる（0.15 秒）。弱点なら大きく赤い ×。
- ダメージの数字が当たった所から浮いて 0.8 秒で消える。白、弱点は黄色で大きく。
- 撃墜: 部品が 3〜5 個はじけ飛び、煙を出しながら落ちる。2 秒後に部品（落とす物）を落として消える。

## 遠距離武器（スリング → 銃）

すべて同じ仕組み（飛ぶ弾）で動き、項目 `ranged` の値だけが違う。**遠距離は最強にしない**: 遠いほどばらつきで当たりにくく、距離で弱くなる。弾は物として飛び、重力で落ち、目に見える。

| 項目 | 意味 |
| --- | --- |
| `ammo` | 使う弾の物（石、ガラクタ弾） |
| `dmg` | 攻撃力（満タンまで引いたとき・1 発） |
| `speed` | 弾の速さ（m/秒） |
| `drop` | 重力の効き方（1 = ふつう、0 = まっすぐ） |
| `spread` | ばらつき（度）`[止まって, 動いて, 覗いて]` |
| `draw` | 引く秒数（スリング。引いた分で速さと攻撃力が 40%〜100%）。0 なら押してすぐ撃つ |
| `rate` | 次を撃てるまでの秒 |
| `mag` / `reload` | 弾倉の数と込め直しの秒（銃）。なければ 1 発ずつ持ち物から |
| `falloff` | 距離の減り方 `[ここまで 100%, ここで最小, 最小の倍率]` |
| `recoil` | 撃ったときに視点が上へはねる角度（度）。0.2 秒で戻る |
| `aim` | 右クリックで覗き込めるか。覗くと視野が 0.75 倍（0.15 秒でなめらかに寄る・戻る。腕の構えと同じ速さ）、歩く速さ半分 |

| 武器 | 攻撃力 | 速さ | ばらつき | 引く・連射 | 弾倉・込め直し | 減り方 |
| --- | --- | --- | --- | --- | --- | --- |
| スリング | 5 | 28 | 1.5° / 4° / - | 引く 1 秒 | 1 発ずつ（石） | [12m, 30m, 30%] |
| ガラクタ拳銃 | 10 | 90 | 2° / 5° / 1° | 連射 0.6 秒 | 5 発・R で 2.2 秒 | [10m, 35m, 35%] |
| AK47（作り直し・サイバー版とも） | 5 | 150 | 1.5° / 4° / 0.6° | 0.1 秒・押している間撃つ | 30 発（小銃弾）・R で 2.0 秒 | [25m, 70m, 40%] |

- **撃ち方**（`ranged` の項目、2026-10-22）: `auto` = 押している間 `rate` ごとに撃つ。`burst` = 1 回押すと `burst` 発を `burstGap` 秒ごとに撃ち、そのあと `rate` 待つ。どちらもなければ 1 回押して 1 発。
- **弾切れ**: クリップで動く銃（下の「銃の仕組み」）は弾切れで撃つと「カチッ」と鳴るだけ（込め直しは R）。ガラクタ拳銃は今どおり、弾切れで撃つと込め直しを始める。
- **画面のはね**（`recoil` 度）: 撃つたびに視点が上へ `recoil` はね、左右へ ±30% のどちらかへ少しずれる。押している間は戻らずに積み上がる（最大で `recoil` の 10 倍）。離すと 0.3 秒で戻る。
- **小銃弾**（2026-10-22）: AK47 の弾。今は射撃訓練島の補充だけ（作り方・設計図は段階 8 で決める）。形は銅の薬きょうに鉄の弾頭のついた弾 4 本を並べた物（弾の束の目安）。

- **ガラクタ弾の見た目**（2026-10-17）: 銅の薬きょう 5 本を丸く並べて、さびた鉄のバンドで束ねた形（幅 約 7cm・高さ 約 6cm）。先は鉄のとがり。手に持つ・落ちている・アイコンとも同じ形（極小の目安）。
- 弾は敵・ヤシの実・鳥の巣・地形・木・岩・建築パーツに当たる。当たらなかったスリングの石はそのまま消える。
- 弾数は画面の右下に「4/5」のように出す（銃だけ）。
- 込め直しは R（建築中の R は今までどおり回す）。込め直しの途中で持ち替えると取りやめ。

## 武器の動きと演出（2026-10-17 決定。PLAN.md「戦闘の演出」）

手の動きは `src/avatar/fpMotion.js`（武器ごとのポーズの表）、手の組み立ては `src/avatar/fpHands.js`、銃の動きは `src/avatar/fpGun.js`。

- **3 段の振り**: 構え（ため・グッ: ゆっくり入って一瞬止まる）→ 振り（放出・バッ: 速く出て止まる）→ 戻り（ゆっくり）。当たりの判定は振りの終わり（武器ごとの割合）。振りの途中で次を振るときは、今のポーズから 0.08 秒でつなぐ（飛ばない）。
- **ため攻撃**: ためている間に、ため攻撃の構え（大きく引く・頭の上まで振りかぶる）へ少しずつ入り、満タンで震える。離すと構えを飛ばしていきなり振る。
- **当てた・外した**: 当てたら振りが一瞬止まり（0.05 秒、重い武器ほど長く 0.09 秒まで）、手と道具が振りと逆へ跳ね返る（重い武器ほど大きく）。外したら振りの向きへ少し振り抜けてから戻る。
- **重さ**: 武器の `stam` から（12 で 1）。重いほど 振り抜け・跳ね返り・歩く揺れが大きい。
- **歩く・見回す**: 歩くと武器が 8 の字に揺れる（遅く歩く間は小さく。走るができたら大きく）。視点を回すと手が少し遅れてついてくる。
- **持ち替え**: 新しい物は画面の下から 0.2 秒で出てくる（クリップで動く銃は「銃の仕組み」の持ち替え）。

| 武器 | 振り | ため攻撃 |
| --- | --- | --- |
| やり | 後ろへ引いて一気に突き出し、戻す。続けて（1 秒以内）突くと左右に少し角度を変える | 大きく引いて、体ごと（両手とも）前へ突き出す |
| 斧・ピッケル・ハンマー・その他の持ち物 | 右上へ振りかぶり、左下へ斜めに振り下ろす | 頭の上まで振りかぶって真下へ |
| ナイフ（剣ができたら同じ動き） | 横なぎ（右 → 左）と返し（左 → 右）を交互に。刃を寝かせる。速い | 右へ大きくひねって、強い横なぎ |
| 素手 | 左右の手で交互にまっすぐパンチ | 右手を大きく引いて強いパンチ |
| スリング | 引くほど手が後ろ・下へ下がり、震えが大きくなる。袋（石入り）が手前へ伸び、ひもが張る（最大 0.25m）。放つと袋が前へはじけ、少し震えて元へ。石がないときは袋は空 | - |

- **振りの軌跡**: 近接武器（素手は除く）を振ると、刃先の通り道に白い帯（`P.fx.swing`）が 0.15 秒残る。ため攻撃は太く、0.22 秒。新 `src/combat/swingFx.js`。
- **ガード**: 武器を横に寝かせて顔の前に構え、左手で支える。**ガード中は攻撃できない**（ためも始めない。ため中にガードしたらためを取りやめ）。受けると腕が後ろへはじかれる（受けた攻撃力ほど大きく）。受け流しは武器の前に白い閃光と火花（`P.fx.swing`・`P.fx.spark`）。
- **銃（ガラクタ拳銃は回転式なので、スライド＝撃鉄、弾倉＝回転弾倉）**: 撃つと上へはね、少し下がって戻る。撃鉄が後ろへ倒れて戻り、弾倉が 1/5 回る（弾切れでは撃鉄が倒れたまま）。**リロード**（込め直しの秒に合わせる）: 銃を傾けて下げる（0〜15%）→ 左手で弾倉を横へ抜いて画面の下へ（15〜40%）→ 新しい弾倉を持って上がり、差し込む（40〜70%）→ 左手で撃鉄を起こす（70〜90%）→ 構え直す（90〜100%）。覗き込みは今どおり。
- **銃の軌道**: 弾の玉は見せない（飛び方・重力・ばらつき・当たり方は今のまま）。撃った瞬間に、同じ飛び方で先に当たる所を調べ、銃口からそこまで光る線（芯 `P.fx.tracer[0]`・ふち `[1]`）を引く。線は 0.1 秒で細くなって消え、薄い煙の筋（`P.fx.tracerSmoke`）が 0.5 秒残って少し広がる。最長 120m。スリングの石は今どおり見せる。

## 銃の仕組み: クリップで動く銃（2026-10-22 決定。PLAN.md「銃を持って撃つ」）

`gun-export/` の 13 丁を作り直した銃（今は AK47 とサイバー版）は、手で動きを書かず、**export の動き（クリップ）をそのまま流す**。中身と再生の決まりは `gun-export/README.md`、数値は `guns.json`。ガラクタ拳銃は今の動き（fpGun.js）のまま。

- **データ**: glb は実行中に読まない（素材ファイルを使わない決まり）。`scripts/gunClips.mjs` で glb の動きを読み、向きを変え、間引いて `src/survival/gunClips/<銃>.js` に書く。構えの値（`vm`）もそこへ写す。
- **向き**: export は前が −Z・右が +X、作り直しは前が +z・左が +x（Y 軸で 180° 回した関係）。位置は (−x, y, −z)、回転（四元数）は (−qx, qy, −qz, qw) に変える（変換スクリプトの中で）。
- **組み方**: 構えの入れ物（カメラの中、README の向き。腰だめ・覗き込み・`kick`・持ち替え・画角合わせ）→ 裏返し（Y に 180°、大きさ `vm.scale`）→ 銃の一番上のノード（クリップだけが動かす。ほかから位置や向きを書かない）→ 動く部品（`carrier`・`mag`・`trigger`・`lhand`）。
- **流し方**: 一度に 1 つ（three の AnimationMixer、LoopOnce）。`fire` は `inspect`・`equip` を止める、`reload` は `inspect` を止める、込め直し中は `inspect` を受け付けない、`equip` は全部を止めて流す。止まった部品は元の位置へ戻る。込め直しは `reload` の速さを `clips.reload.dur / 込め直しの秒` にする。出来事（`eject`・`magOut`・`magIn`・`rack` など）は、流れた時刻が通り過ぎたフレームに 1 回ずつ出す。
- **手**: 右手は銃の一番上のノードの握り（export の `hand_R` の位置）に付ける（込め直しの途中で銃が手から離れない）。左手は `lhand` ノードについていく（export の木の手は使わない）。猫の手は銃に合わせて小さくする（export の手と同じくらい）。
- **重ねない**: 持ち替えは `equip` クリップ＋README の持ち替えの式（下から 0.2 秒で出るのは使わない）。揺れは今の歩く揺れ・見回しの遅れを入れ物に足す（README の `sway` は使わない）。反動は画面のはね（上の「画面のはね」）と、銃の `kick`（README の式）の両方。
- **画角**: `vm` は銃を描くカメラの縦の画角 58°（覗き込みで 50°）のときの値。このゲームは 1 つのカメラなので、入れ物の x・y を `tan(今の縦の画角/2) / tan(銃の画角/2)` 倍して、画面での位置を合わせる（今の縦の画角は覗き込みの拡大も入れる）。
- **覗き込み**: export の `ads` は照準が真ん中に来ないので使わない。作り直しの形の照準（後ろの照準のみぞと、前の照準の先）を結ぶ線がカメラの真ん中を通るように、向きと位置を形から決める。
- **眺める**: T キー（キー設定で変えられる）で `inspect` を流す。込め直し中は受け付けない。撃つと止まる。
- **薬きょう**: `eject` の出来事で、排莢口から右前・上へ飛び、重力で落ちて 1〜2 回はねて 3 秒で消える（銅の小さな柱、極小の目安。同時に最大 40 個）。最初に地面に当たると「チャリン」と鳴る。
- **銃口の火**: 大きさは銃ごと（`flash` 倍、なければ 1）。連射を 1 秒以上続けると、撃つたびに銃口から薄い煙（`P.fx.tracerSmoke`）が少し上る。
- **音**: `sound.md`。銃声は銃ごとの `snd`、出来事の名前の音、弾切れのカチッ、薬きょう。

## 攻撃間隔（マイクラ風。2026-10-17 決定）

武器ごとの `cd`（振ってから次を振れるまでの秒）。**満ちるまで次を振れない**。なければ `swing` と同じ。照準の下の線（ui.md「戦闘の表示」）で見せる。斧・ピッケルで木や岩を叩くときも同じ。遠距離武器は `rate`（連射の間隔）と込め直しを同じ線で見せる。

| 武器 | cd |
| --- | --- |
| 素手 | 0.4 |
| ナイフ | 0.5 |
| やり | 0.7 |
| 斧 | 0.9 |
| ピッケル | 1.0 |

## 受けたときの揺れの重さ（2026-10-17 決定。上の「受けたとき」の揺れを置きかえる）

揺れ方は**受けた攻撃の攻撃力**（ガードで減る前）で決める。間は線でつなぐ。

| 攻撃力 | 大きさ | 秒 | 速さ（1 秒に揺れる回数） | 視点の横の傾き |
| --- | --- | --- | --- | --- |
| 10 | 0.06 | 0.25 | 22 | 0 |
| 30 | 0.14 | 0.4 | 14 | 0.04 ラジアン |
| 50 | 0.24 | 0.6 | 8 | 0.09 ラジアン |

- ガードで受けたときは大きさ半分。手も少し後ろへはねる。

## サイバーガンシリーズ（2026-10-22 決定。ユーザー案）

実銃の作り直し（style.md「実銃（例外）」、`akShapes.js`）とは**別ルールの別物**。黒い箱の組み合わせに、銃ごとに 1 色のネオンの線が光る。元の絵は 8 種（名前・種類・色）: TACK ハンドガン ice / HORNET SMG volt / EMBER アサルトライフル ember / TRIAD 3 点バースト violet / LANCET DMR mint / NEEDLE スナイパー crimson / BRICK ショットガン rose / COMET ロケット solar。実銃の形（AK47 など）をこの作りにすることもある（色は 8 色から選ぶ。サイバー版 AK47 は rose）。

- **形**: 角を面取りした箱だけで組む（丸い部品・ロフトは使わない）。輪郭は元の銃・絵に合わせる。図形の数は絵より増やしてよいが、面の数はこのゲームの細かさに合わせる（style.md「サイバーガン（例外）」）。
- **色**: 本体の大きな箱は黒、銃床・ハンドガード・細い部品は灰色（palette.js の `cyber`）。**面取りの細い面だけ明るい灰色**にして、絵の縁取りを表す（輪郭線は使わない）。面ごとの明るさの揺らぎは今どおり。
- **ネオン**: 面から少し浮かせた薄い板。照明を受けない材質（光るキノコと同じ）で、銃の色 1 色だけ。置く所は、本体の横の長い線・前の箱の横の線・弾倉の横の四角い窓・銃口の前の四角など、絵の位置に合わせる。
- **まわりのもや（光のにじみ）は付けない**。線そのものだけが光る。
- **ネオンの色は世界の色と合わせなくてよい**（例外）。値は palette.js の `cyber.neon` にだけ置く。
- 動く部品の分け方（carrier・mag・trigger・銃口・排莢口）は実銃の作り直しと同じ。
