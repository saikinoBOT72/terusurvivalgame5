# 島ごとの設計

島の地図・区域・資源の量・敵の配置・出口の条件。島に共通の仕組み（畑・鉱石・設計図）は `survival.md`、形は `objects.md`、敵の数値は `enemies.md`、物語は `story.md`。

## 島の作り方（2026-10-16 決定）

- **マップは固定**。島ごとに「区域の下絵（文字の地図）」を手で描き、細かい凹凸はノイズで足す。乱数の種は島ごとに決めた値で固定する。
- 島の**中身**（地形・置く物・敵）と**位置**（海のどこにあるか）は分けて持つ。後から島の位置だけ変えられるようにする。
- セーブは島の番号ではなく**島の名前**で戻す。
- 固定なので、地形は思い切って作る（崖、峡谷、滝、高台、海食崖）。ただし通れる道は必ず 1 本は残す。
- 島ごとに雪の高さを決める（雪のない島もある）。

### 敵の出方（2026-10-19 段階 6 で一新。置き方は islandMap.js の spawns と wild）
敵の出方は 2 種類。**距離で強さを変える倍率は入れない**（やるならレベル制。PLAN.md「後で」）。
- **固定湧き**: その場所を守る敵。行けば必ず戦う。スポットの番人（spawns の `spot` の行）と、決まった場所の敵（`at: { x, z }` の行。`mode`・`n` も付けられる。島の図のウィジェットで置いた敵もこれ）。
- **自然湧き**: 決めた範囲（`wild`）の中にランダムに出る。強さは固定湧きと同じ（弱くしない）。

- 出る所（マイクラのように、湧いた瞬間を見せない）: その範囲の円の中の、その区域の字の、プレイヤーから **60〜110m**（かすみで見えなくなるのが 115m）の立てる場所。90m より近い所は、**カメラの正面（向きから左右約 60° 以内）を避ける**。範囲の端からプレイヤーが 110m より遠いと、その範囲は出さない。

- 昼・夜が変わったとき、上限より多い分は、戦っていなくてプレイヤーから 30m より遠いものから消す。
- 戦っていなくて **160m** より遠くなったら消える（上限の数が空くので、また出る）。
- 80m より遠くて気づいていない敵は休む（動かない。軽くするため）。出たばかりの遠い敵は、近づくまで動かない。

### 島を出る

## 開発用の射撃訓練島（2026-10-17 決定）

好きな敵を出して武器を試すための島。開発中（`import.meta.env.DEV`）だけ、メニューの開発用ボタン「射撃訓練島」から入る。製品版には出ない。セーブしない。昼で止める。
- **島の形**: 約 120m 四方の平らな草地と、まわりの砂浜・海（カニが海へ逃げる、物が浮くのも試せる）。墜落島の生成は使わない。
- **召喚の台**: 低い石の台を横に並べる（ブンブン・カニ・ガラクタ犬・採掘ロボ・ガンギ・練習用の的）。台の上でその敵の小さな模型（0.25 倍）がゆっくり回る。右クリックで台の 10m 前にその敵がプレイヤーのほうを向いて出る（ガンギは 15m 前）。端に「全部消す」（敵を全部消す）と「武器を補充」（地面の武器を出し直す）の台。
- **地面の武器**: 石のやり・鉄のやり・石のナイフ・鉄の斧・スリング・ガラクタ拳銃・ガラクタ弾 30・石 20 を落とし物として置く（右クリックで拾う）。
- **射撃の道**: 10・20・30・40・50m に距離の杭（数字の札）と練習用の的。
- **体**: HP・スタミナ・受けたときの見せ方は本番と同じ。空腹・水分は減らない。HP が 0 になったら倒れずに満タンに戻る。
