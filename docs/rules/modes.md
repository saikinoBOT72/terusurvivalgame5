# モード（サバイバル・PvP の分け方）

2026-10-22 決定。核は共通にして、遊び方ごとの決まりは「モード」に分ける。

## 分担

| | 共通（核） | サバイバルだけ | PvP だけ |
| --- | --- | --- | --- |
| 動く・見る | 1人称、物理、乗り物、カメラ、画面の効果 | | 霧の見える距離の下限 40m、被弾の色ずれ（style.md「画面の効果」） |
| 戦う | 近接・遠距離・銃、スタミナ、HP と倒れる | 敵の出方（固定湧き・自然湧き） | （これから: リスポーン、武器の選び方、点数） |
| 作る | 建築の仕組み、パーツ | 素材を使う建築 | マップ作り（素材なし・飛べる） |
| 生きる | | 空腹など（survival.md）、昼夜の進み、畑、眠る | |
| 持ち物 | 持ち物・装備の仕組み | 島の持ち物・大事な物 | 自分の持ち物（島の物と混ぜない） |
| セーブ | | 島のセーブ（つづきから） | マップのセーブ（mapMaker.js） |
| 世界 | 世界の切り替え（game/worlds.js） | 島、射撃訓練島（開発用） | マップ作りの世界 |

- モデル確認島はどちらでもない「見るだけ」のモード。
- **マップ作りと PvP の試合は別の物**: マップ作りは PvP のマップを作る道具。試合（遊ぶ所）はあとで PvP モードの上に作る。
- 世界の性質（飛べる・素材なしで建てる＝`world.mapMaker`、訓練島では倒れない＝`world.range`）は世界に残す。モードは「どの決まりで遊ぶか」を持つ。

## モードの形（`src/modes/`）

1 つのモードは次を持つ（無い物は `modes.js` の初めの値）。

- `id`: `survival`・`pvp`・`view`
- `owns(w)`: その世界がこのモードの物か
- `enter()`・`exit()`: モードが替わるとき（持ち物の入れ替えなど）。同じモードの中で世界を移っても呼ばない
- `onPlay(w)`: その世界で遊び始めるたび
- `survival(w)`・`fighting(w)`・`statusHud(w)`: 空腹などが進むか、敵とスタミナが動くか、HP の表示を出すか
- `pvp`: PvP の画面の効果を使うか
- `update(dt, w)`: 1人称で遊んでいる間（眠っている間は呼ばない）の、モードだけの 1 フレーム
- `saveNow()`: 一時停止・ページを閉じるときの保存

main.js はモードの中身を知らない。`world === island` のような分かれ道は main.js に書かず、モードに聞く。
