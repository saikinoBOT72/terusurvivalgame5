# アバター（猫・仮のキャラ）のルール

猫の見た目・動き・1人称の腕を作るときに読む。参考は、ユーザーが共有した猫の6方向の画像（正面・背面・左右・上・底）。

## 例外: 面の細かさ

- キャラクターは style.md の「面の粗さをそろえる」の対象外。世界の物より細かい面で作ってよい（頭は横 14 分割、胴は横 16 分割くらい）。
- フラットシェーディング、面ごとの明るさの揺らぎ、パレットの色だけを使う、は他と同じ。

## 体の形

- **全高**: 耳の先まで約 1.4m。目の高さ（1人称のカメラ）は約 1.1m。
- **頭身**: 約 2.5 頭身。頭は胴と同じくらいの幅で大きい。首はなく、頭が胴に直接のる。
- **頭**: 丸く、頬が少しふくらむ。口元が少し前に出る。
- **耳**: 頭の上の両端に三角の耳。少し外に開く。内側はピンク。
- **目**: 縦の細い線 2 本（太さ 0.02・長さ 0.083 = 頭の高さの 23%・間隔 0.098）。高さは頭の下から 47%。絵の寸法から。頭の表面を調べてぴったり付ける。
- **鼻**: 小さなピンクの三角。目の間の少し下。
- **胴**: 下が太い卵形。
- **白い部分**: 口元・あご・胸・お腹が1つにつながった形（よだれかけのように、顔の下半分からお腹まで）。背中と頭の上はオレンジ。
- **腕**: 短く太い。少し前に出して構える。手は白で、手のひら側にピンクの肉球。
- **脚**: 短い。茶色の四角いブーツ。
- **しっぽ**: 太め。腰の後ろから出て、後ろへ伸びてから斜め上に曲がる。先が白い。

## 作り方

- 頭・胴・腕・脚・しっぽ・耳を別々のパーツで作り、関節で回せるようにつなぐ。
- 目と鼻は、頭の表面の位置を調べて、表面にぴったり付ける。
- 色は palette.js の catOrange・catWhite・catPink・eye・boots だけを使う。

## 動き

- 歩く: 脚を交互に振る。腕は脚と逆に振る。体が少し上下に弾む。しっぽが左右に揺れる。
- 立ち止まる: 呼吸で体がわずかにふくらむ。しっぽがゆっくり揺れる。ときどき耳がぴくっと動く。
- 動きはなめらかでよい（コマ送りにしない）。

## 1人称での見え方

- 画面の下に、オレンジの腕と白い手が見える。手のひら側にピンクの肉球。
- 道具は手に持った状態で表示し、使うと短く振る動きをする。

## 仮のキャラ（2026-10-14〜10-23。**本番キャラに入れ替えて `simple.js` は消した**。git の履歴から戻せる。下は当時の記録）

ユーザーの絵をもとにした簡単なキャラだった。

- **全高**: 約 1.35m。目の高さ（1人称のカメラ）は今のまま 1.1m。
- **胴**: 縦長の角の丸い箱（幅 0.45m・高さ 0.85m・奥行き 0.35m）。
- **頭**: 横長の角の丸い箱（幅 0.6m・高さ 0.45m）。胴の上に直接のる。
- **目**: 縦の細い線 2 本（太さ 0.02・長さ 0.083 = 頭の高さの 23%・間隔 0.098）。高さは頭の下から 47%。絵の寸法から。頭の表面を調べてぴったり付ける。
- **手**: 腕と足はなく、丸い小さなかたまりが体の横に浮く。
- **足**（2026-10-23 決定「E5」）: 脚なし。体の底に平べったい足がくっつく（長さ 0.36・幅 0.2・高さ 0.08m、左右の間隔 0.2m、前へのびる）。浮かせない（体の底が足にめり込む）。足の案（浮く足・細い脚・ずんぐり脚・長い脚・薄い足）は捨てた。
- **色**: 肌は全部 catWhite（胴・頭・手・足。2026-10-23 一旦白）、目は eye。
- **使う所**（2026-10-23 入れ替え済み）: 起動画面で島をまわる体（main.js、`BODY` 0.8 倍）、1 人称の両手（手の形 `handGeo` は体の手と同じ丸い手。動きは fpHands.js のまま）、モデル確認島。

- **動き**: 歩くと体が少し弾み、手が前後にゆれる。立ち止まると、手がゆっくり上下する。
- **1人称**: 画面の下に両手だけが見える。右手に物を持ち、使うと手ごと振る（やりは前に突く）。
