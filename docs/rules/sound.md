# 音（2026-10-22 決定。PLAN.md「銃を持って撃つ」）

音の決まり。数値は表だけに書く（コードは `src/audio/`）。

## 作り方

- **音のファイルは使わない**（素材ファイルを使わない決まり）。Web Audio でコードから作る（雑音・正弦波・フィルター・音量の形）。雑音のもとは 1 回だけ作って使い回す。
- **始める**: ブラウザは、ユーザーが一度クリックするまで音を出せない。最初のクリック（マウスを捕まえたとき）で音を始める。それより前に鳴らした音は捨てる。
- **音量**: 設定の「音量」（全体、0〜100%、はじめは 70%。ui.md「設定の窓」の「音」のタブ）を全部の音に掛ける。
- **場所**: 鳴らすときに場所を渡せる（渡さなければ自分の音）。遠いほど小さく（2m までそのまま、そこから距離に反比例、80m より遠いと鳴らさない）、左右は聞く人の向きで振り分ける。敵の音・マルチの相手の銃声にも使う。

## 銃の音

| 音 | 作り方 |
| --- | --- |
| 銃声 | 低い「ドン」（下がっていく正弦波）＋ 雑音の破裂（すぐ消える）＋ 高い「パン」（ごく短い高い雑音）＋ 雑音の尾（ゆっくり消える）。銃ごとの `snd` の値で太さ・高さ・長さを変える |
| `magOut`（弾倉を抜く） | 金属のカチャ（短い高い雑音 2 つ）＋ 擦れる音 |
| `magIn`（弾倉を入れる） | 重いガチャン（低い響き＋短い雑音） |
| `rack`（ボルトを引く） | 引くカシャと戻すガシャの 2 つ（0.08 秒あける） |
| `insert`・`slap`・`close` | `magIn` と同じ作りで高さだけ変える（残りの 12 丁で使う） |
| カチッ（弾切れで撃つ） | ごく短い高いクリック |
| 薬きょう | 高い金属の「チャリン」（3〜4 つの高い正弦波がすぐ消える。毎回少し高さを変える） |

| `snd` | 低い音の高さ（Hz） | 尾の長さ（秒） | 破裂の明るさ（Hz） | 大きさ |
| --- | --- | --- | --- | --- |
| `rifle`（AK47） | 95 → 40 | 0.45 | 2400 | 1 |
| `pistol`（ガラクタ拳銃） | 140 → 55 | 0.3 | 3200 | 0.85 |

- ガラクタ拳銃の込め直しの音: 弾倉を横へ抜く所で `magOut`、差し込む所で `magIn`、撃鉄を起こす所で `rack`（fpGun.js の割合）。
