# 追加する物の候補（2026-10-14 提案）

選んだ物だけ、使い道を決めてルールのファイル（survival.md、objects.md、building.md）に移す。ここは候補の置き場で、決定ではない。

**2026-10-14**: ユーザーが選んだ物は PLAN.md「次の目標」の表に移した。猫らしさの仕組みは入れない。組み合わせ料理・図鑑・畑・石炭や鉄の岩はあとで。ここには、まだ選ばれていない物が残っている。

- **★** = 序盤（ステップ7）に入れるのがおすすめ
- **出典** = 参考にしたゲーム。マイクラ以外からも広く取る（Valheim、Raft、Don't Starve、The Forest、ゼルダ BotW、どうぶつの森、Stardew Valley、Subnautica、Grounded など）
- 使い道のない物は作らない。「今」と「後」の両方を書く

## 1. 方向づけ（マイクラっぽくしないための柱）

| 柱 | 出典 | 中身 |
| --- | --- | --- |
| 浜辺に流れ着く | Raft | 浜辺に流木・ひも・たまに珍しい物が流れ着き、時間で戻る。集める場所が「島の内側」だけにならない。動く拠点（船）にもつながる |
| 猫らしさ | オリジナル | またたび、魚、日なたぼっこ、段ボール箱、爪とぎ。猫だからできること・うれしいことを仕組みに入れる |
| 快適な家で休む | Valheim | 寝床・たき火・家具がそろった屋根の下で休むと「くつろぎ」（しばらく HP の回復が速い、空腹の減りが遅い）。家を飾る理由になる |
| 組み合わせ料理 | ゼルダ BotW | 後で、鍋に 2〜3 個入れると組み合わせで効果が変わる。今は「焼く」だけ |
| 植えて育てる | Don't Starve、Stardew | 木を切ると苗が出る、木の実を植えると茂みになる。「木と岩は戻らない」問題の答えにもなる |
| 集めて埋める図鑑 | どうぶつの森、Subnautica | 魚・虫・キノコ・不思議な物を見つけると図鑑に載る。後の探索ゲームの軸になる |
