# ファイルの地図

どのファイルが何をしているか。ファイルを足したり役割が変わったりしたら、ここも直す。

## src

| ファイル | 役割 |
| --- | --- |
| `main.js` | つなぎ込み: 共通の仕組みを作ってつなぐ、画面の切り替え（menu / fps / dead）、世界の切り替え（見えるのは今の世界だけ・モードを替える）、1 フレームの流れ、開発用の `window.__game`（`gameMode` で今のモード）。サバイバル・PvP だけの事は modes/ |
| `input/keymap.js` | キーの割り当て: 動作の表（ACTIONS）、キーとマウスボタンの名前、変える・入れ替え、押しているキー（`down`。タッチのスティックは `setExtra`）。`oasobi5.keys` |
| `input/mouseKeys.js` | マウスの中・サイドボタンをキーと同じ keydown / keyup（Mouse1・Mouse3・Mouse4）にする。サイドボタンの戻る・進むを止める |
| `input/mobileGuard.js` | スマホのブラウザの邪魔な動き（拡大・スクロール・長押しの選択とメニュー）を止める。向きを変えたら大きさを合わせ直す。全画面にできなければ `no-fs` |
| `ui/update.js` | アップデート: 公開中の版（version.json）と今の版を比べる、読み直す。版は vite.config.js がビルドで入れる |
| `input/touch.js` | タッチ操作の入力: 使うか（自動・使う・使わない）、`playing(dom)`（固定中かタッチ中）、スティック（倒し方で忍び足・歩く・走る）、なぞった視点、ボタン → キー・クリック |
| `controls.js` | 遊び中の操作: マウスの固定、クリック（左=壊す、右=使う）、ホイール、キー（Esc で一時停止。全画面のロック中も）、照準の下のヒント |
| `debug.js` | 開発用: `__game.debug()` が状態（画面、位置、持ち物、照準、建築、物理など）を文字で返す。`__game.physics.test(n)` で石を落とす。`__game.mob('drone')` で目の前に敵を出す。`__game.run(ms)` で画面が隠れていても ms だけ進める。`__game.stats()` が今ある物の大きさ・三角形・部品の数を返す。`debug()` の「重さ」の行は perf.js |
| `perf.js` | 開発用: 重さを測る。1 フレームの時間を仕組みごと（世界・物理・敵・描画など）に平均し、fps・描画の回数・三角形の数と一緒に `__game.debug()` に出す |
| **modes/** | モード（docs/rules/modes.md）。main.js はモードに聞く |
| `modes/modes.js` | モードの入れ物: 今のモード、世界からモードを引く、切り替え（exit → enter）。見るだけのモード（`VIEW`、ほかのモードの初めの値） |
| `modes/survival.js` | サバイバル: 島を作る（ロード画面）・タイトルの景色・はじめから・つづきから・セーブ、空腹・時刻・敵の出方の 1 フレーム、射撃訓練島を開く |
| `modes/pvp.js` | PvP: マップ作りを開く、自分の持ち物（島の持ち物を預かって入れ替える）、PvP の画面の効果の印。試合はあとでここに |
| **game/** | main.js から分けたつなぎ込み |
| `game/renderer.js` | 描画の準備（影・大きさ）、マウスの固定、1 フレームの描き方（世界 → 1人称の腕を重ねる） |
| `game/postfx.js` | 画面の効果: 設定の細かさで HDR の画面に描く → 光る物が映ったときだけブルーム → まとめ → SMAA → 拡大とシャープ処理。重いとき自動で細かさを下げる。`__game.post`、画質の切り替えは `__game.quality("low")` |
| `game/postfxShaders.js` | 画面の効果のシェーダー（縮小・しきい値・拡大のブルーム、まとめ、CAS の拡大） |
| `game/held.js` | 手に持つ物の見た目、持っている間だけ光る物（松明・光るキノコ）と減り方。スリングは動く形（slingRig）で持つ |
| `game/building.js` | 建築のつなぎ込み: 置くと素材が減る、撤去すると半分戻る・設備の中身を返す、いかだが壊れる、建築メニュー |
| `game/mapMaker.js` | マップ作り: 世界を作る、変えるたびに自動で保存（`oasobi5.map`）、ファイルへの書き出し・読み込み（記録 v2 は広さと空と色も入る）、広さの変更、ジャンプ台・飛ばし台で跳ばす |
| `game/mapEnv.js` | マップ作りの空と色の値（時刻・日の光・空・霧・グレーディング）と、sky.setOverride・world.grade に渡す形 |
| `ui/mapWin.js` | マップの設定の窓（建築メニューのボタンから。タブ「広さ」「空と色」） |
| `game/life.js` | HP などの状態、倒れる・起きる（寝床のそば）、夜に眠る、たき火のそば |
| `game/worlds.js` | 世界を切り替えたとき: 建築パーツ・物理・乗り物を初めてのときに作り、各仕組みに今の世界を渡す |
